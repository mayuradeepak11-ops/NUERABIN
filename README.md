# NUERABIN Rescue ♻️
### AI-Powered Smart Waste Segregation for a Cleaner Future

## About the Project

**NUERABIN Rescue** is an AI-powered smart waste management website designed to promote responsible waste disposal and improve waste segregation. The project aims to help people understand how to separate waste correctly, reduce environmental pollution, and encourage sustainable habits.

Developed as part of a college hackathon, NUERABIN Rescue explores how Artificial Intelligence can contribute to a cleaner, greener, and more sustainable world.

## Problem Statement

Improper waste disposal and the mixing of different types of waste make recycling difficult and contribute to environmental pollution. Many people are unaware of the correct methods for segregating everyday waste.

There is a need for an accessible, technology-driven solution that helps people make better waste disposal decisions.

## Our Solution

NUERABIN Rescue aims to address these challenges through an AI-powered digital platform that supports smarter waste management.

### Key Features

- **AI Integration:** Uses AI technology to support intelligent waste management.
- **Smart Waste Segregation:** Promotes the correct separation and disposal of different waste categories.
- **User-Friendly Interface:** Provides an accessible website experience.
- **Environmental Awareness:** Encourages responsible waste disposal and recycling.
- **Sustainability-Focused Design:** Supports cleaner communities and environmentally conscious habits.

*Note: The features listed above describe the project's goals. Actual functionality depends on the features implemented in the current version.*

## Objectives

- Reduce improper waste disposal.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.10 or later, compatible with your dependencies
- pip (Python package installer)
- A Google AI API key if required by your implementation
- Git (optional, for cloning the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

**2. Navigate to the project folder**

```bash
cd YOUR-REPOSITORY
```

**3. Install the dependencies**

```bash
pip install streamlit google-genai
```

If your project contains a `requirements.txt` file, use:

```bash
pip install -r requirements.txt
```

**4. Configure your API key**

Store your Google AI API key securely. Avoid hardcoding API keys in your source code or uploading them to GitHub.

For local development, you can configure Streamlit secrets in `.streamlit/secrets.toml`:

```toml
GOOGLE_API_KEY = "your-api-key-here"
```

Make sure this file is excluded from version control.

**5. Run the application**

```bash
streamlit run app.py
```

Replace `app.py` with your actual Python filename if it is different.

The application will open in your browser, usually at:

`http://localhost:8501`
